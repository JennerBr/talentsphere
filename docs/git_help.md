# principais comandos git

### verificar instalação do git

`git --version`

### Preparar - marcar o início do commit
`git add .`
`git add file1.ts file.js`


permite que seja selecionado apenas alguns arquivos que foram modificados. Demais modificações que ainda não estão prontas não serão comitadas.

### trocar de branch
`git checkout nome-da-branch`

### Confirmar - fazer commit
`git commit -m "mensagem do commit"`

so entra o que passou no git add.

### desfazer commit
`git reset --soft HEAD~1`
